#네트워크 #오키야토시야

## 1장
- 유선랜
	- 이더넷 : OSI 1~2계층
- 무선랜
	- IEEE 802.11 시리즈
- 스위치
	- L2 : 유선 랜을 묶는 것
	- L3 : 네트워크와 네트워크를 연결하는 기능 (라우팅이 가능함)
	- L4 (TCP로 배분 가능) 또는 L7 (APP 레벨에서 배분 가능): 부하 분산 및 애플리케이션에 맞게 통신을 제어할 수 있는 고급 스위치
- 무선 액세스 포인트 (무선 랜 라우터)
	- 무선 랜을 묶는 것 
- ONU
	- 광 회선과 공유기를 연결하고 광 신호와 디지털 신호를 변환하는 장치
- 라우터
	- 네트워크와 네트워크를 연결하는 기능이 있는 네트워크 장비
	- 라우터와 L3 스위치의 차이점은?
- 가상 라우터
	- VPC (Virtual Private Cloud) : 퍼블릭 클라우드를 가상 프라이빗 클라우드로 이용하는 기술 = 가상 데이터 센터
	- VPC 쪽 연결점이 가상 라우터
		- 라우터는 전용 하드웨어로 제공
		- 가상 라우터는 클라우드에서 실행되는 소프트웨어로 제공
- 인터네트워킹
	- 복수 네트워크를 서로 연결하는 것
	- 장점 
		- 불필요한 통신을 네트워크 전체로 확산시키지 않는다
		- 고장이 나도 영향이 광범위하게 퍼지는 것을 막을 수 있다
		- 개별 네트워크를 각 조직의 방침에 따라 관리할 수 있다
- 조직(AS)
	- Autonomous System (자율 시스템)
	- 인터넷을 구성하는 단위 = 어느 하나의 관리 주체로 보유 및 운용되는 독립된 네트워크
- tracert : 실행한 PC => 목적지 PC 가는 네트워크 IP 주소 검색 
	- unix : traceroute 
- 프로토콜
	- 통신하기 위한 공통된 약속
	- TCP/IP가 주류

## 2장
- TCP/IP
	- 인터넷 프로토콜 스위트 = 다른 컴퓨터 벤더나 운영체제, 서로 다른 회선끼리 통신할 수 있게 하는 통신 프로토콜 세트
	- Transmission Control Protocol / Internet Protocol

| 4   | 응용 계층      | HTTP, DNS 등         | 애플리케이션에 맞추어서 통신한다.                        |
| --- | ---------- | ------------------- | ----------------------------------------- |
| 3   | 전송 계층      | TCP, UDP            | IP와 애플리케이션을 중개해서 송신된 데이터를 확실하게 전ㄷ라한다.     |
| 2   | 인터넷 계층     | IP, ICMP, ARP 등     | 네트워크 주소를 기반으로 수신 측 컴퓨터까지 데이터를 전송한다.       |
| 1   | 네트워크 접근 계층 | 이더넷, 무선 랜(Wi-Fi) 등0 | 컴퓨터를 물리적으로 네트워크에 연결해서 기기 간에 전송할 수 있게 한다.  |
- IP 주소
	- Private IP 주소 : 랜 내부에서 사용되는 주소
	- Global IP 주소 : 인터넷에서 사용되는 주소
- MAC 주소
	- 이더넷에서는 하드웨어끼리 통신 상대를 특정하고자 MAC 주소를 사용
	- TCP/IP에서는 통신 상대를 특정하고자 IP 주소를 사용
- ARP 주소
	- Address Resolution Protocol
	- 같은 네트워크에 속한 컴퓨터끼리 통신할 때는 우선 IP 패킷을 보내고 싶은 상대의 MAC 주소를 조사하고, 그 MAC 주소로 패킷을 보내는 흐름.
	- IP주소에 대응하는 MAC 주소를 알아내기 위해 네트워크 전체에 패킷을 보냄 (ARP Request)
	- 자신을 찾는 것을 안 컴퓨터가 응답함 (ARP Reply)
- 다른 네트워크와의 통신
	- 라우터(또는 L3 스위치)가 필요함
	- 다른 네트워크의 IP 주소와 통신할 때, 미리 지정된 기본 게이트웨이 IP 주소로 통신을 보낸다. 
- 패킷
	- 통신할 때 데이터를 교환하는 방법
		1. 회선 교환 : ex) 전화기. 데이터를 교환하는 동안 계속해서 회선을 점유하는 방식
		2. 패킷 교환 : 주고받는 데이터를 '패킷' 이라는 작은 덩어리로 나누고, 회선을 공용해서 복수의 통신을 내보내는 방식
	1. 운송 정보 = 헤더
	2. 화물 = 페이로드
 - IP 주소 분석
	 - DHCP : 라우터에서 IP 주소를 자동으로 할당받는 기술
		 - Dynamic Host Configuration Protocol
		 - DHCP Discover : Client => Server : DHCP 서버 찾으려고 함
		 - DHCP Offer : Server => Client : 클라이언트에게 설정을 제안하는 통신을 보냄
		 - DHCP Request : Client => Server : 제안된 설정의 세부사항을 요청함.
		 - DHCP ACK : 설정의 세부사항을 지정하는 통신을 함
	 - 서브넷 마스크
		 - IP주소는 네트워크 + 호스트 구성 
		 - 192.168.1 (네트워크) + .1 (호스트)
		 - ex) S/M : 255.255.255.0
		 - 네트워크 주소 : 192.168.1.0
		 - 브로드캐스트 주소 : 192.168.1.255
