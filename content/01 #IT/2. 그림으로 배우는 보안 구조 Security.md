#보안 #마스이토시카츠

## 1장
- 보안의 3요소
	- 기밀성 Confidentiality
		- 허가된 것만 사용 가능하다.
	- 완전성 Integrity
		- 내용이 올바른 상태를 유지한다.
	- 가용성 Availability
		- 장애 발생으로 인한 영향을 받지 않게 한다. 
- 안전성은 비용이나 편리성과 상반됨. Tradeoff.
- 접근권한, 인증, 인가, 최소 권한의 원칙. 

## 2장
- 스푸핑 Spoofing
	- IP 스푸핑 : 특정 IP 주소로만 연결할 수 있는 서비스를 자신의 IP 주소로 위장하여 연결하는 방법
- rootkit : 관리자 권한을 사용하여 시스템을 조작하는 도구들의 집합
- DDos : Distributed Denial of Service
- 방화벽
	- 패킷 필터링
- IDS, 침입 탐지 시스템 (Intrusion Detection System)
	- NIDS : 네트워크 IDS
		- 방화벽 다음에 위치한 장비
	- HIDS : 호스트 IDS
		- 각 단말PC별로 설치하는 장비
- IPS, 침입 방지 시스템 (Intrusion Prevention System)
- UTM : 종합아이템 (Unified Threat Management)
- SIEM (Security Information Event Management)
- DMZ (Demilitarized Zone) : 외부에 공개하는 영역
- SSID Stealth : 무선LAN AP의 식별자인 SSID를 숨기는 기능. 보안 측면 효과는 한정적임.
- 무선 LAN 암호화 방식
	- WEP : 예전 방법. 이제는 사용 안함.
	- WPA 또는 WPA2
	- 접속하는 단말기를 제한하려면 IEEE 802.1X 인증을 수행하면 된다.
